# Renting System

Sistema de renting de vehículos desarrollado con:

- Java
- Spring Boot
- Arquitectura Hexagonal
- PostgreSQL
- API REST
- Frontend desacoplado

## Arquitectura

- Backend separado del frontend
- Arquitectura hexagonal
- Escalable y mantenible

## Tecnologías

- Spring Boot
- Spring Data JPA
- Spring Security
- PostgreSQL
- HTML/CSS/JavaScript
